## Project overview

This notebook analyzes the ProPublica COMPAS two-year recidivism dataset. It loads and filters the data, prepares predictor variables, trains two models, and performs statistical and fairness-related analyses.

## Notebook contents

1. Import libraries and configure the random seed.
2. Load and filter the COMPAS dataset.
3. Inspect selected features, missing values, and IQR outliers.
4. Split the data into training and testing sets.
5. Train and compare a Linear Regression model and a Logistic Regression model.
6. Examine the association between prior offences and recidivism across groups.
7. Compare full and reduced models to examine omitted-variable bias.
8. Identify high-confidence incorrect predictions and summarize the selected cases.
9. Calculate group fairness metrics across classification thresholds.
10. Export analysis tables as CSV files and the fairness trade-off plot as an image.

## Dataset
